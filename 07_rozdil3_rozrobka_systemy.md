# 3 РОЗРОБКА ПРОГРАМНОГО ЗАБЕЗПЕЧЕННЯ ІНФОРМАЦІЙНОЇ СИСТЕМИ ДЛЯ ІНФОРМАЦІЙНОГО РЕСУРСУ ВІДЕОІГОР

## 3.1 Проєктування архітектури інформаційної системи

Одним із ключових етапів проєктування програмної системи є вибір архітектурного підходу, який забезпечить зручність реалізації, модульність та подальшу масштабованість системи. Для інформаційної системи для інформаційного ресурсу відеоігор було обрано архітектуру ASP.NET Core Razor Pages, яка дозволяє чітко розділити логіку представлення, обробки даних та взаємодії із зовнішніми сервісами.

Архітектура системи складається з трьох основних компонентів:

- рівень представлення - відповідає за відображення даних у зручному для користувача форматі. Розроблений інтерфейс базується на HTML5, CSS3 і Bootstrap, що забезпечує адаптивність та естетичність дизайну;
- сервісний рівень - містить логіку взаємодії між сторінками, зовнішніми API та джерелами даних. Реалізовано обробку запитів, агрегацію пропозицій, конвертацію валют і формування пов’язаних посилань;
- рівень даних - містить логіку збереження та обробки даних. У даній системі пропозиції та історія цін зберігаються локально у базі SQLite, що дозволяє реалізувати повноцінне збереження інформації без використання окремого серверного СКБД-рішення.

Оскільки система має серверну частину і використовує зовнішні HTTP-запити, її реалізовано у вигляді вебзастосунку, який поєднує сторінкову модель ASP.NET Core, окремі сервіси інтеграції та локальне сховище даних.

На рисунку узагальнено принципи взаємодії між основними рівнями системи:

- представлення (View) - отримує команди від користувача і передає їх сторінковій логіці;
- сторінкова та сервісна логіка - керує діями користувача, викликає зовнішні сервіси та оновлює дані;
- модель даних - зберігає інформацію, яка при потребі оновлює інтерфейс.

Обрана архітектура дозволяє:

- швидко розширювати систему новими сервісами без кардинальної зміни структури;
- ефективно реалізувати функції пошуку, перегляду, оновлення пропозицій та збереження історії цін;
- легко адаптувати систему під нові потреби користувачів шляхом розширення або заміни окремих компонентів.

## 3.2 Вибір інструментальних засобів розробки програмного забезпечення

Для реалізації інформаційної системи для інформаційного ресурсу відеоігор було обрано набір інструментальних засобів, які забезпечують гнучкість, швидкість розробки, простоту у використанні та відповідність сучасним стандартам створення вебзастосунків.

Основу програмного забезпечення становить ASP.NET Core Razor Pages та мова програмування C#. Завдяки цьому забезпечено зручну організацію сторінок, маршрутизацію та взаємодію із зовнішніми сервісами.

Для стилізації застосовано каскадні таблиці стилів CSS3 у поєднанні з фреймворком Bootstrap, який забезпечує адаптивність інтерфейсу, відповідність сучасному дизайну та зручність використання готових компонентів.

Клієнтська логіка реалізована з використанням JavaScript, що забезпечує взаємодію між користувачем і програмною логікою системи на рівні допоміжних динамічних елементів сторінки.

Для зберігання інформації використано SQLite, яка дозволяє зберігати структури даних без використання окремої серверної інфраструктури баз даних. Це рішення повністю задовольняє потреби системи на етапі MVP, оскільки всі необхідні дані доступні локально та не вимагають складного розгортання.

Як основне середовище розробки використано Visual Studio Code. Цей редактор коду надає широкий спектр можливостей: підсвічування синтаксису, автозаповнення, перевірка помилок у реальному часі, інтеграція з git, використання розширень, що значно прискорює та оптимізує процес розробки.

Для тестування й перевірки адаптивності системи застосовувався браузер Google Chrome, а саме його вбудовані інструменти розробника DevTools. За їх допомогою перевірялась коректність HTML-структури, робота сторінкової логіки, відображення елементів у різних режимах та коректність даних, отриманих із зовнішніх сервісів.

Таким чином, обрані інструментальні засоби дозволили розробити інформаційну систему, яка поєднує зручний інтерфейс, зовнішні інтеграції та локальне збереження даних. Усі компоненти відповідають актуальним вимогам до сучасного веброзроблення.

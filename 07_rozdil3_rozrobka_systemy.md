# 3 РОЗРОБКА ПРОГРАМНОГО ЗАБЕЗПЕЧЕННЯ ІНФОРМАЦІЙНОЇ СИСТЕМИ

## 3.1 Архітектура системи

Одним із ключових етапів проєктування програмної системи є вибір архітектурного підходу, який забезпечить зручність реалізації, модульність та подальшу масштабованість системи. Для інформаційної системи для інформаційного ресурсу відеоігор було обрано архітектуру ASP.NET Core Razor Pages із виділенням рівнів представлення, сервісів інтеграції та доступу до даних.

Обрана архітектура складається з кількох основних компонентів:

- рівень сторінок `Pages` відповідає за маршрутизацію, побудову інтерфейсу та взаємодію користувача із системою;
- сервісний рівень `Services` реалізує інтеграцію із зовнішніми джерелами даних, зокрема RAWG, Steam, CheapShark та НБУ;
- рівень даних `Data` забезпечує збереження пропозицій і параметрів відстеження в локальній базі даних SQLite.

## 3.2 Інструментальні засоби

Для реалізації системи було використано:

- ASP.NET Core Razor Pages;
- мову програмування C#;
- HTML5, CSS3, Bootstrap;
- JavaScript для допоміжної клієнтської логіки;
- SQLite для збереження пропозицій та історії цін;
- зовнішні HTTP API та вебджерела.

## 3.3 Основні можливості реалізованого застосунку

Реалізований застосунок `GamesInfoSys` підтримує:

- перегляд каталогу відеоігор;
- сторінку деталей гри з описом, платформами, рейтингами та зовнішніми посиланнями;
- завантаження метаданих через RAWG;
- отримання цінових пропозицій із Steam та CheapShark;
- приблизну конвертацію цін у гривню за курсом НБУ;
- збереження історії пропозицій у базі даних SQLite;
- швидкі переходи до офіційних магазинів, українських маркетплейсів і YouTube-пошуку.

## 3.4 Висновки до розділу

Обрані технології дозволили створити гнучкий вебзастосунок, який поєднує зручний інтерфейс, зовнішні інтеграції та локальне збереження даних. Такий підхід забезпечує можливість подальшого розширення системи без радикальної зміни її структури.
